NetBar - About

NetBar is a network traffic monitoring tool for macOS that tracks real-time upload and download speeds with detailed per-process traffic statistics and weekly reports.

Key Features

Real-Time Monitor

Live upload/download speed in menu bar

Per-Process Tracking

Monitor network usage by individual applications

Traffic Charts

Visual traffic history with interactive charts

Weekly Reports

Detailed weekly network usage summaries

System Requirements

  • macOS 14.0 or later
  • At least 2GB RAM
  • At least 50MB free storage

Usage Guide

Basic Operations

  1. Launch NetBar — it appears in the menu bar automatically
  2. View real-time upload/download speeds at a glance
  3. Click the menu bar icon for detailed charts
  4. Browse per-process traffic and weekly reports

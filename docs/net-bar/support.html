About This App

NetBar is a lightweight network traffic monitor that sits in your macOS menu bar. It provides real-time visibility into your network activity with a clean, minimal interface.

  • Real-Time Traffic Display - View live upload and download speeds directly in the menu bar with customizable units and refresh rates.
  • Traffic History Graph - Visualize network activity over time with an interactive graph showing speed fluctuations.
  • Per-Interface Monitoring - Monitor traffic on specific network interfaces (Wi-Fi, Ethernet, VPN) independently.
  • Data Usage Tracking - Keep track of total data consumed per session, day, or month with automatic reset options.

Permissions & Privacy

Required Permissions:

  • Network Access - Required to read network interface statistics and traffic data for display in the menu bar.

Privacy Commitment: All network monitoring is performed locally on your device. No traffic data, browsing history, or usage statistics are ever transmitted to any server. Your online activity remains completely private.

Frequently Asked Questions

  • What does NetBar monitor? - Real-time upload and download speeds, per-process traffic, and weekly reports.
  • Does it require admin privileges? - Some advanced features may require a helper tool with elevated privileges.
  • Can I monitor multiple interfaces? - Yes, you can switch between Wi-Fi, Ethernet, and VPN interfaces in the settings.
  • Does NetBar work with macOS firewalls? - Yes, NetBar is compatible with macOS built-in firewall and common third-party firewalls.
  • How do I uninstall NetBar? - Quit the app and delete it from your Applications folder. If a helper tool was installed, it will be removed automatically.
  • The app won't launch? - Ensure your Mac meets the minimum requirements: macOS 14.0 or later.

Troubleshooting

  • Traffic showing 0 on all interfaces - Restart NetBar. If the issue persists, reboot your Mac to reset network statistics.
  • Graph not displaying data - Ensure you have selected the correct network interface. Try switching to a different interface and back.
  • Menu bar text too wide - Switch to compact display mode in settings, or change the unit format to reduce text width.
  • Data usage counter resets randomly - Check that the app has permission to write to its data storage. Reinstall if the database is corrupted.

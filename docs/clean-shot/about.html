CleanShot - About

CleanShot is a powerful macOS screen capture tool that provides a professional screenshot experience.

Key Features

Multiple Capture Modes

Fullscreen, region, window, and scrolling capture

Built-in Editor

Annotations, arrows, blur, text, and more

History

Auto-saves screenshot history for easy access

Keyboard Shortcuts

Customizable shortcuts for efficient workflow

System Requirements

  • macOS 12.0 or later
  • At least 2GB RAM
  • At least 100MB free storage

Usage Guide

Basic Operations

  1. Click the menu bar icon to start capture
  2. Select the capture area or window
  3. Use editing tools to add annotations
  4. Save or share the screenshot

📸 CleanShot - 产品说明

CleanShot 是一款功能强大的 macOS 屏幕截图工具，为您提供专业级的截图体验。

主要功能

多种截图模式

支持全屏、区域、窗口和滚动截图

内置编辑器

标注、箭头、模糊、文字等编辑工具

历史记录

自动保存截图历史，方便查找

快捷键支持

自定义快捷键，操作更高效

系统要求

  • macOS 12.0 或更高版本
  • 至少 2GB RAM
  • 至少 100MB 可用存储空间

使用说明

基本操作

  1. 点击菜单栏图标启动截图
  2. 选择截图区域或窗口
  3. 使用编辑工具添加标注
  4. 保存或分享截图

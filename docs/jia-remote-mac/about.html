JiaRemoteMac - About

JiaRemoteMac is the macOS server (host) component of a local network remote desktop solution. It captures the screen using ScreenCaptureKit and streams it to the Windows client, while receiving keyboard and mouse control commands over TCP/UDP.

Key Features

Screen Capture

High-quality screen capture via ScreenCaptureKit

LAN Discovery

Bonjour-based automatic network discovery

Remote Control

Receive keyboard and mouse inputs remotely

Low Latency

Optimized TCP/UDP protocol for minimal lag

System Requirements

  • macOS 12.3 or later
  • At least 4GB RAM
  • Screen Recording permission
  • Accessibility permission (for remote input)

Usage Guide

Setup

  1. Launch JiaRemoteMac on your Mac
  2. Allow Screen Recording and Accessibility permissions when prompted
  3. The app will automatically advertise itself on the local network
  4. Connect from JiaRemoteWin on your Windows PC

隐私政策

最后更新：2026 年 7 月

感谢您使用「管住嘴」（以下简称"本应用"）。我们非常重视您的隐私。本隐私政策说明我们如何收集、使用和保护您的信息。

1. 信息收集

本应用不会收集您的任何个人身份信息。所有数据（包括挑战记录、充值余额等）均仅存储在您的设备本地，不会上传至任何服务器。

2. 内购支付

本应用提供金币充值功能，通过 Apple 的 StoreKit 框架进行处理。支付交易由 Apple 直接处理，本应用无法获取您的支付信息（如银行卡号、Apple ID 密码等）。

3. 数据存储

所有应用数据仅保存在您设备的 UserDefaults 中。删除应用即会清除所有数据，且无法恢复。请自行做好数据备份。

4. 第三方服务

本应用不使用任何第三方分析工具、广告 SDK 或数据追踪服务。应用启动时会从远程地址拉取文案配置，该请求仅限于获取 JSON 配置文件，不包含任何用户标识信息。

5. 儿童隐私

本应用不面向 13 岁以下儿童，也不会故意收集儿童的个人信息。

6. 政策变更

我们可能会不时更新本隐私政策。重大变更时，我们会在应用内通知您。

7. 联系我们

如您对本隐私政策有任何疑问，请通过 huiyu9144@outlook.com 与我们联系。

⏱️ DashTimer - 产品说明

DashTimer 是一款轻量级菜单栏计时器，简洁美观，功能实用。

主要功能

倒计时模式

设置自定义倒计时时间

正计时模式

记录经过的时间

快捷操作

菜单栏快速访问和控制

提醒通知

计时结束时发送通知提醒

系统要求

  • macOS 12.0 或更高版本
  • 至少 2GB RAM
  • 至少 50MB 可用存储空间

使用说明

基本操作

  1. 点击菜单栏图标打开计时器
  2. 设置时间或选择预设
  3. 点击开始计时
  4. 计时结束会收到通知

版本信息

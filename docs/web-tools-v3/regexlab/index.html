正则表达式语法速查表
.匹配任意单个字符（除换行符）
\d匹配数字 [0-9]
\w匹配字母数字下划线 [a-zA-Z0-9_]
\s匹配空白符
^匹配行首
$匹配行尾
*匹配前一个元素 0 次或多次
+匹配前一个元素 1 次或多次
?匹配前一个元素 0 次或 1 次
{n,m}匹配前一个元素 n 到 m 次
(...)捕获组
(?:...)非捕获组
(?=...)正向先行断言
(?!...)负向先行断言
[abc]字符集，匹配 a、b 或 c
\|逻辑或

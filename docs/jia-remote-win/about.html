JiaRemoteWin - About

JiaRemoteWin is the Windows client component of a local network remote desktop solution. It connects to JiaRemoteMac on macOS, receives the live screen stream, and sends keyboard and mouse controls.

Key Features

DirectX Rendering

Hardware-accelerated rendering via DirectX 11 with HLSL shaders

LAN Scanning

Auto-detect JiaRemoteMac hosts on the local network

Remote Control

Send keyboard and mouse events to the Mac host

Low Latency

Optimized TCP/UDP protocol for responsive control

System Requirements

  • Windows 10 or later
  • .NET 9.0 Runtime
  • DirectX 11 compatible GPU
  • At least 4GB RAM

Usage Guide

Basic Operations

  1. Launch JiaRemoteWin on your Windows PC
  2. The app will scan for JiaRemoteMac hosts on the network
  3. Select a Mac from the discovered list
  4. Start remote control session

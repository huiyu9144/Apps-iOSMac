# FormatQuick — 批量格式转换

## 参考通用要求

> 本提示词需要配合 `_shared-requirements.md` 一起使用。所有通用的架构、多语言、性能、关闭/退出机制、设计规范等要求均已在该文件中定义，此处不再赘述。

---

> ⚠️ 原名 **FavConvert**，为避免与现有 App 名称冲突改为 **FormatQuick**

## 项目概述

macOS 菜单栏批量图片格式转换工具。拖入图片 → 选择目标格式 → 一键转换。支持 WebP / HEIC / AVIF / PNG / JPG / GIF。

- **定价**：$4.99 买断
- **目标用户**：设计师、电商卖家、需要跨格式转换的 Mac 用户
- **SF Symbol**：`"arrow.triangle.swap"`

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 拖拽区域 | 顶部 | 接受图片文件或文件夹拖拽 |
| 格式选择按钮 | 中部 | Radio 按钮组，只能选一个目标格式 |
| 质量滑块 | 格式下方 | 0-100% Slider，HEIC/AVIF 默认 80%，JPG/WebP 默认 90% |
| 调整尺寸 | 选项区 | 开关 + 宽/高输入框；开启后自动缩放 |
| 🔄 开始转换 | 操作区 | 启动批量转换，进度条实时显示 |
| 预览区域 | 底部进度下方 | 显示当前正在处理的图片缩略图 + 文件名 |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- 使用 `NSImage` + `CGImageDestination` 系统原生编码/解码
- WebP/AVIF 支持：macOS 14.0+ 原生支持，无需额外库
- HEIC 支持：macOS 10.13+ 原生支持
- 并发处理：`TaskGroup` 最多 4 个并发
- 转换进度通过 `AsyncStream` 实时通知 UI
- 转换完成自动打开输出文件夹

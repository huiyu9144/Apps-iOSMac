## 项目概述

macOS 菜单栏 App 图标替换工具。内置 500+ 精美图标库，一键替换任何 App 的图标，一键恢复默认。

- **定价**：免费（基础 50 图标）→ $4.99 买断（全部图标 + 批量替换）
- **目标用户**：喜欢美化 Mac 桌面的用户、设计师
- **SF Symbol**：`"app.gift"`

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 🔍 搜索 App | 顶部搜索框 | 搜索系统中已安装的 App |
| App 列表 | 左侧 | 展开/收起目录，显示每个 App 当前图标状态 |
| 风格筛选 | 图标区上方 | 按风格分类筛选图标 |
| 图标网格 | 中部 | 点击图标打开预览弹窗 |
| 🎨 图标风格 Tag | 筛选栏 | 线条/拟态/霓虹/毛玻璃/3D/Minimal |
| 已应用统计 | 底部 | 显示当前已替换图标的数量 |
| 🔄 全部恢复默认 | 底部 | 一键恢复所有 App 为系统默认图标 |
| 预览弹窗 | 图标点击后 | 显示应用后效果 + Dock 栏模拟 |
| 应用此图标 | 预览弹窗 | 执行图标替换（确认后写入） |
| 恢复默认 | 预览弹窗 | 恢复该 App 到系统默认图标 |
| ★ 标记 | App 列表 | 表示该 App 已自定义图标 |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- 图标文件存储在 App Bundle 的 `Assets` 目录，按需加载
- 图标替换使用 `NSWorkspace` 的 `setIcon(_:forFile:)` API
- App 列表使用 `NSWorkspace.shared.runningApplications` + `FileManager` 扫描 `/Applications`
- 图标库使用懒加载（只加载当前显示的 20 个预览图）
- 替换前自动备份原图标到 `~/Library/Application Support/IconDock/Backups/`
- "全部恢复默认"直接从备份目录恢复
- 后台不运行任何进程，图标替换是即时一次性操作

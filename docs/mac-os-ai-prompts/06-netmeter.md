# NetMeter — 网络流量监控

## 参考通用要求

> 本提示词需要配合 `_shared-requirements.md` 一起使用。所有通用的架构、多语言、性能、关闭/退出机制、设计规范等要求均已在该文件中定义，此处不再赘述。

---

> ⚠️ 原名 **NetGuard**，因与现有 Android App 重名，改为 **NetMeter**（与 MenuMeter 命名统一）

## 项目概述

macOS 菜单栏网络流量监视器。实时显示上传/下载速度，查看各 App 联网情况，快捷限制 App 联网。

- **定价**：$4.99 买断
- **目标用户**：关注网络流量的 Mac 用户、带宽敏感用户
- **SF Symbol**：`"antenna.radiowaves.left.and.right"`

## 核心功能与 UI 流程

### 菜单栏显示

- 空闲时：仅显示图标
- 有流量时：显示 `↑1.2 ↓3.5 MB/s`
- 实时刷新间隔：1 秒

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 实时图表切换 | 右上角 | 切换显示实时折线图（最后 60 秒流量趋势） |
| 联网进程列表 | 中部 | 点击某进程可对其操作：右键 → 查看详情 / 复制 PID |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- **核心：使用 `nstat` API 读取网络流量，不轮询文件**
- 使用 `NWPathMonitor` 监听网络状态变化（Combine 框架）
- 进程流量：通过 `lsof -i` 解析或读取 `/proc/net`（POSIX）
- 菜单栏每秒更新一次，面板关闭时暂停所有数据收集
- 趋势数据存储在内存环形缓冲区（最近 60 秒 + 最近 7 天）
- 不写入磁盘，重启后不保留历史数据（隐私优先）

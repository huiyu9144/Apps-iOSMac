## 项目概述

macOS 菜单栏强制休息工具。工作一段时间后全屏遮盖强制休息，不可跳过。真正保护视力，解决久坐问题。

- **定价**：$2.99 买断
- **目标用户**：长时间用 Mac 工作、有视力疲劳/颈椎问题的用户
- **SF Symbol**：`"eye"`

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 模式选择 | 面板中部 | Radio 按钮切换工作模式 |
| 播放/暂停 | 模式下方 | 启动/暂停监测定时器 |
| 进度条 | 剩余时间下方 | 可视化显示当前工作阶段进度 |
| 白名单编辑 | 白名单区域 | 选择休息期间可继续使用的 App |
| ⏸ 暂停监测 | 面板底部 | 暂停监测 1 小时（显示倒计时） |
| 跳过按钮 | 休息遮罩层 | 15 秒倒计时后可点击，每天限 3 次 |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- 计时器使用 `Timer.publish(every:tolerance:on:in:)` 带 tolerance（省电）
- 全屏遮罩层使用 `NSScreen` + 无边框 `NSWindow` 覆盖，key level `.screenSaver`
- 面板关闭时后台计时器继续运行（用系统 `DispatchSourceTimer` 而非 UI Timer）
- 通知使用 `UNUserNotificationCenter`（即使 App 不在前台也能提醒）
- 菜单栏图标只在工作时显示倒计时，空闲时只显示图标
- 电池优化：使用 `ProcessInfo.processInfo.thermalState` 感知热状态，过热时降低刷新率

# MuteMate — 智能麦克风管理

## 参考通用要求

> 本提示词需要配合 `_shared-requirements.md` 一起使用。所有通用的架构、多语言、性能、关闭/退出机制、设计规范等要求均已在该文件中定义，此处不再赘述。

---

## 项目概述

macOS 菜单栏麦克风/摄像头隐私管理器。检测到视频会议 App 启动时自动静音，一键全局静音/取消静音快捷键。

- **定价**：$3.99 买断
- **目标用户**：远程办公、频繁参加视频会议的用户
- **SF Symbol**：`"mic.slash"`

## 核心功能与 UI 流程

### 菜单栏显示

- 麦克风开启时：🎤 图标（亮色）
- 麦克风静音时：🔇 图标（灰色 + 斜杠）
- 摄像头激活时：📷 图标闪烁（可选）

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 🔇 一键静音 | 面板中部 | 全局静音所有 App 的麦克风；状态切换为一键恢复 |
| App 列表 | 面板中部 | 显示当前使用麦克风/摄像头的进程列表 |
| 自动静音规则 | 规则区 | 勾选开关：进入会议自动静音 / 摄像头激活自动静音 / 离开会议恢复 |
| 最近活动 | 底部 | 事件时间线日志 |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 全局快捷键

- `⌘ + ⇧ + M`：一键静音/取消静音（全局优先级最高，覆盖所有 App）
- 快捷键可在设置中自定义

### 性能要求

- 使用 `CoreAudio` API 检测麦克风状态变化（音频路由回调）
- 使用 `RunningApplications` 监控进程启动/退出（`NSWorkspace.shared.notificationCenter`）
- 不使用轮询，纯事件驱动
- 快捷键使用 `CGEvent` + `addGlobalMonitorForEvents` 捕获
- 内存 < 10MB
- 不支持登录项时提示用户手动添加

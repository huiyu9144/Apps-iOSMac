> 本提示词需要配合 `_shared-requirements.md` 一起使用。所有通用的架构、多语言、性能、关闭/退出机制、设计规范等要求均已在该文件中定义，此处不再赘述。

## 项目概述

macOS 菜单栏批量图片压缩工具。拖入图片或文件夹 → 选择压缩级别 → 一键压缩全部。完全离线，不上传服务器。

- **定价**：$3.99 买断
- **目标用户**：设计师、电商运营、自媒体创作者
- **SF Symbol**：`"arrow.down.to.line.compact"`

## 核心功能与 UI 流程

### 首次启动

1. 显示 macOS 授权弹窗（读取文件权限 — `NSOpenPanel` 选择文件夹）
2. 菜单栏出现压缩图标（灰色箭头向下）

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| ⚙️ 齿轮图标 | 右上角 | 打开设置窗口（快捷键 `Cmd+,`） |
| 📂 选择文件/文件夹 | 顶部 | 弹出 `NSOpenPanel`，支持多选；选中后显示文件数量和总大小 |
| 压缩质量选项 | 中部 | 四个 Radio 按钮，默认"高"；无损：PNG 原样/JPEG 100%；高：90%；中：70%；低：40% |
| ⬇ 压缩并导出按钮 | 中部 | 开始批量压缩；按钮变为取消按钮；压缩完成后自动弹出导出选择 |
| 进度条 | 中部 | 实时显示当前进度（百分比 + 完成数/总数） |
| 压缩结果 | 进度下方 | 显示压缩前后对比（总大小 + 减少百分比） |
| 支持格式 | 底部提示 | 显示 PNG / JPG / WebP / AVIF 图标 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- 使用 `CGImageDestination` + `CGImageProperties` 系统原生编码器（不上传服务器）
- 批量压缩使用 `TaskGroup` 并发处理，最多同时处理 4 张
- 单张图片压缩 < 0.5 秒（1920x1080 JPEG）
- 不压缩时内存 < 15MB，压缩时 < 50MB
- 导出时写入临时目录，完成后移动到用户选择位置

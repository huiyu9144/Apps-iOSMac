## 项目概述

macOS 菜单栏窗口分屏管理工具。拖拽窗口到屏幕边缘自动贴边分屏，快捷键快速布局。替代 Magnet 的平价方案。

- **定价**：$2.99 买断
- **目标用户**：需要多窗口布局的效率型 Mac 用户
- **SF Symbol**：`"rectangle.split.2x1"`

## 核心功能与 UI 流程

### 首次启动

1. 弹出辅助功能权限授权弹窗（System Preferences → Privacy → Accessibility）
2. 无权限时显示提示页面引导用户开启
3. 授权后菜单栏出现分屏图标

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 左/右/上/下/角布局按钮 | 面板网格 | 将当前活跃窗口移动到对应位置 `setWindowPosition(.left)` |
| 居中按钮 | 下方 | 将窗口居中显示 |
| 全屏按钮 | 下方 | 将窗口全屏 |
| ⚙️ 齿轮 | 右上 | 打开设置 |
| 快捷键提示 | 底部 | 显示当前所有快捷键绑定 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 快捷键（默认）

- `⌘ + ⌥ + ←`：左半屏
- `⌘ + ⌥ + →`：右半屏
- `⌘ + ⌥ + ↑`：全屏/最大化
- `⌘ + ⌥ + ↓`：还原/居中
- `⌘ + ⌥ + U`：左上
- `⌘ + ⌥ + I`：右上
- `⌘ + ⌥ + J`：左下
- `⌘ + ⌥ + K`：右下

### 性能要求

- 不启动后台定时器，完全由事件驱动（`NSEvent.addGlobalMonitorForEvents(matching:)`）
- 拖拽检测使用 `CGEvent` + `AXUIElement` API（Accessibility）
- 窗口变换使用 `AXUIElementSetAttributeValue` 直接操作，不轮询
- 空闲内存 < 10MB
- 注册为 `Login Item` 开机自启（可选）

### 关键实现

```swift
// 窗口贴边检测逻辑
func mouseDragHandler(_ event: NSEvent) {
    guard let screen = NSScreen.main else { return }
    let mouseLoc = NSEvent.mouseLocation
    let edgeThreshold: CGFloat = 5.0

    if mouseLoc.origin.x <= edgeThreshold {
        snapWindowTo(.left)
    } else if mouseLoc.origin.x >= screen.frame.width - edgeThreshold {
        snapWindowTo(.right)
    }
}
```

### 多次未授权时的处理

- 每次启动检测 Accessibility 权限
- 无权限时：弹出引导窗口，内含系统偏好设置路径 + 解锁锁头图标指示
- 不阻塞使用：面板正常显示，但布局按钮灰色不可点击，hover 时显示"需要辅助功能权限"

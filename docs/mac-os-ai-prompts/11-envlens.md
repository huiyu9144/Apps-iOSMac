## 项目概述

macOS 菜单栏 .env 文件管理器。扫描本地项目，可视化查看/编辑环境变量，加密存储敏感值，一键导出 .env.example。

- **定价**：$3.99 买断
- **目标用户**：开发者、devops 工程师
- **SF Symbol**：`"key.icloud"`

## 核心功能与 UI 流程

### 首次启动

1. 弹出文件夹权限授权窗口（选择包含 .env 文件的项目根目录）
2. 保存授权路径到 `SecurityScopedBookmark`，下次自动恢复

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 项目下拉筛选 | 顶部 | 按项目名称筛选 |
| 项目列表 | 中部 | 展开/收起每个项目的 .env 文件；🔒 表示敏感值已加密 |
| 🔍 搜索变量 | 工具栏 | 搜索所有项目中的变量名或值 |
| 选中变量详情 | 详情区 | 点击某变量后显示 Key=Value |
| 📋 复制值 | 详情区 | 复制变量值到剪贴板 |
| ✏️ 编辑 | 详情区 | 内联编辑变量值，保存时加密敏感值 |
| 🗑 删除 | 详情区 | 删除该变量（确认弹窗） |
| 📤 导出 .env.example | 工具栏 | 自动去除敏感值，生成 .env.example |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- 使用 `FileManager` 遍历目录，仅扫描 `.env*` 文件
- 文件监听使用 `DispatchSourceFileSystemObject`，变更时自动刷新
- 敏感值加密使用 `Security` framework（`SecKeychain`）
- 扫描路径使用 `SecurityScopedBookmark` 保存权限
- 打开项目列表使用懒加载（只展开当前选中的项目）
- 搜索使用 `Combine` + 防抖（300ms）

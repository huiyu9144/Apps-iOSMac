> ⚠️ 原名 **MockAPI Studio**，为统一命名风格改为 **MockFlow**（与 ClipFlow 呼应）

## 项目概述

macOS 菜单栏本地 Mock API 服务器。图形化创建 API 端点，一键启动/停止本地服务。前端开发调试利器。

- **定价**：$5.99 买断
- **目标用户**：前端开发者、全栈开发者
- **SF Symbol**：`"platter.filled.top.and.arrow.up.phone"`

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 🟢 服务器状态 | 顶部 | 显示运行/停止状态 + 端口号 |
| ⏹ 停止 / ▶ 启动 | 状态旁 | 切换服务器状态 |
| 🔄 重启 | 状态旁 | 重启服务器（加载最新配置） |
| API 端点列表 | 中部 | 点击某端点编辑；右侧 ⋮ 菜单：复制/删除/上移/下移 |
| ⋮ 更多 | 端点行右侧 | 弹出菜单：复制路径、删除端点、上下移动 |
| + 新建端点 | 列表下方 | 打开新建端点弹窗 |
| 请求日志 | 日志区 | 实时滚动显示最近请求 |
| 📤 导出配置 | 底部 | 导出为 JSON 文件 |
| 📥 导入配置 | 底部 | 从 JSON 文件导入 |
| ⚙️ 齿轮 | 右上 | 设置（默认端口、CORS 设置） |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- 内置 HTTP 服务器使用 `Network` 框架（`NWListener`）或 `GCDWebServer` 风格，零第三方依赖
- 使用 Swift 原生 `NWConnection`，不引入 Vapor/Perfect 等框架
- 请求日志存储在内存环形缓冲区，最多 200 条
- 端点配置持久化到 `UserDefaults`（JSON 序列化）
- 服务器停止时释放所有端口绑定
- 启动/停止 < 100ms

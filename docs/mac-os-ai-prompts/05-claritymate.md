# ClarityMate — AI 写作助手

## 项目概述

macOS 菜单栏 AI 写作助手。快捷键呼出写作面板 → 选择场景 → 输入或选中文字 → AI 自动改写/生成。使用 Claude API，按量付费。

- **定价**：免费 20 次/月 → $4.99/月
- **目标用户**：需要频繁写英文邮件/推文/LinkedIn 帖子的工作者
- **SF Symbol**：`"pencil.and.outline"`

## 核心功能与 UI 流程

### 首次启动

1. 弹出 API Key 配置窗口（必填：输入 Anthropic Claude API Key）
2. 可选：设置每月预算上限
3. 菜单栏出现写作图标

### 快捷键

- `⌘ + ⇧ + W`：呼出/隐藏写作面板（全局快捷键）

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 场景下拉 | 顶部 | 选择预设场景：邮件回复、推文、LinkedIn 帖子、PR 回复、Bug Report、通用改写 |
| 语气按钮 | 场景下方 | 四选一（正式/简洁/热情/专业），选中高亮 |
| 多行输入框 | 中部 | 输入要处理的文字，支持粘贴 |
| ✨ 生成 | 输入框下方 | 调 API 生成内容；显示 loading + 剩余次数 |
| 结果区域 | 生成按钮下方 | 只读多行文本区，等宽字体显示 |
| 📋 复制 | 结果下方 | 复制结果到剪贴板 |
| 🔄 重新生成 | 结果下方 | 用相同输入重新生成一次 |
| 👍 好用 | 结果下方 | 标记这次生成结果好，用于后续优化提示词 |
| 历史记录 | 底部 | 最近 10 条记录，点击可重新查看 |
| 剩余次数 | 生成按钮旁 | 显示当月剩余免费次数 |
| ⚙️ 齿轮 | 右上 | 设置（API Key、模型选择、预算上限、快捷键） |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- API 调用时显示 loading 动画，不阻塞 UI
- 请求超时时间 30 秒
- 输入防抖（用户停止输入 500ms 后自动保存草稿到 `UserDefaults`）
- API 调用失败时显示友好错误信息 + 重试按钮
- 历史记录存储在 `UserDefaults`，最多保留 50 条
- API Key 存储在 Keychain（`SecItemAdd`），绝不明文保存

### 多语言注意事项

- 场景名称、语气名称全部本地化
- 输入内容本身不翻译（用户写什么就是什么）
- 设置的 API Key 提示也需要中文/英文/日文

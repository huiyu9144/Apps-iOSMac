# HueSnap — 屏幕取色器

## 参考通用要求

> 本提示词需要配合 `_shared-requirements.md` 一起使用。所有通用的架构、多语言、性能、关闭/退出机制、设计规范等要求均已在该文件中定义，此处不再赘述。

---

> ⚠️ 原名 **ColorSnap**，为避免与现有 App 重名改为 **HueSnap**

## 项目概述

macOS 菜单栏取色器。快捷键呼出取色器 → 鼠标悬停任何位置 → 自动复制颜色代码。支持 Hex/RGB/HSL/Tailwind/CSS 变量导出。

- **定价**：$4.99 买断
- **目标用户**：设计师、前端开发者
- **SF Symbol**：`"eyedropper"`

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 开始取色 | 面板顶部 | 快捷键提示，点击触发取色模式 |
| 取色历史列表 | 历史区 | 最近 20 条，点击某条重新选中该颜色 |
| 色板网格 | 色板区 | 点击色块选中；右键删除；拖拽排序 |
| 📋 复制Hex | 底部操作 | 复制当前颜色的 Hex 值 |
| 📋 复制RGB | 底部操作 | 复制当前颜色的 RGB 值 |
| 📋 复制Tailwind | 底部操作 | 复制最接近的 Tailwind 色值 |
| 💾 保存到色板 | 底部操作 | 将当前颜色保存到当前色板 |
| 输出格式下拉 | 面板角落 | 选择默认复制格式 |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- 取色器使用全屏 `NSWindow` + `NSScreen` 截图 → 放大镜渲染
- 像素读取使用 `CGImage` + 位图上下文，< 5ms
- 色板存储在 `UserDefaults`，支持导出导入 JSON
- Tailwind 映射：预计算 200+ Tailwind 色值做最近邻匹配
- 快捷键 `⌘+⇧+C` 注册为全局热键

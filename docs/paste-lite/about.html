📋 PasteLite - 产品说明

PasteLite 是一款智能剪贴板管理器，帮助您高效管理和使用剪贴板历史记录。

主要功能

剪贴板历史

自动记录所有复制内容，随时查看历史

快速搜索

支持关键词搜索，快速定位内容

一键粘贴

点击即可粘贴历史内容

持久保存

重启后历史记录依然保留

系统要求

  • macOS 12.0 或更高版本
  • 至少 2GB RAM
  • 至少 50MB 可用存储空间

使用说明

基本操作

  1. 复制任意内容到剪贴板
  2. 点击菜单栏图标查看历史
  3. 搜索或滚动查找内容
  4. 点击历史项快速粘贴

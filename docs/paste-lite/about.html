PasteLite - About

PasteLite is a smart clipboard manager that helps you efficiently manage and use clipboard history.

Key Features

Clipboard History

Auto-records all copied content for later access

Quick Search

Search by keywords to find content instantly

One-Click Paste

Click any history item to paste immediately

Persistent Storage

History persists even after restart

System Requirements

  • macOS 12.0 or later
  • At least 2GB RAM
  • At least 50MB free storage

Usage Guide

Basic Operations

  1. Copy any content to clipboard
  2. Click the menu bar icon to view history
  3. Search or scroll to find content
  4. Click an item to paste instantly

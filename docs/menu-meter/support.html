About This App

MenuMeter is a comprehensive system monitoring tool that lives in your macOS menu bar. It provides real-time insights into your Mac's performance, helping you keep an eye on system resources at a glance.

  • CPU Monitoring - View real-time CPU usage per core, overall load, and temperature readings.
  • Memory Tracking - Monitor memory pressure, used vs. available RAM, and swap file usage.
  • Disk & Network - Track disk space usage, read/write activity, and network traffic in real time.
  • Customizable Display - Choose which metrics to show in the menu bar and how they are displayed (text, graph, or icon).

Permissions & Privacy

Required Permissions:

  • System Monitoring - Requires access to system statistics (CPU, memory, disk, network) which macOS restricts for security reasons.

Privacy Commitment: All system data is read and displayed locally. No system information is ever collected, logged, or transmitted to any server.

Frequently Asked Questions

  • What does MenuMeter monitor? - CPU usage and temperature, memory usage, disk space, network traffic, and battery status.
  • How do I customize the display? - Click the menu bar icon and navigate to settings to choose which metrics to display.
  • Does MenuMeter affect performance? - MenuMeter is designed to be lightweight and uses minimal system resources.
  • Can I hide specific metrics? - Yes, you can enable or disable each metric individually in the preferences panel.
  • How do I uninstall MenuMeter? - Quit the app and delete it from your Applications folder. No additional cleanup is needed.
  • The app won't launch? - Ensure your Mac meets the minimum requirements: macOS 14.0 or later.

Troubleshooting

  • Metrics not updating - Try restarting MenuMeter. If the issue persists, check if another monitoring app is conflicting.
  • High CPU usage by MenuMeter itself - Reduce the update frequency in settings. Lower refresh rates reduce CPU impact.
  • Temperature readings unavailable - Some Mac models do not expose temperature sensors. This is a hardware limitation.
  • Menu bar text overlapping - Adjust the display format in settings, or reduce the number of visible metrics.

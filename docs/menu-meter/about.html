📊 MenuMeter - 产品说明

MenuMeter 是一款系统监控工具，实时显示 CPU、内存、磁盘、网络等系统状态。

主要功能

CPU监控

实时显示CPU使用率

内存监控

显示内存使用情况

磁盘监控

显示磁盘空间使用

网络监控

显示网络上传下载速度

系统要求

  • macOS 12.0 或更高版本
  • 至少 2GB RAM
  • 至少 50MB 可用存储空间

使用说明

基本操作

  1. 启动应用后自动显示在菜单栏
  2. 点击图标查看详细信息
  3. 可自定义显示内容

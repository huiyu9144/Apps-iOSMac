## 项目概述

macOS 菜单栏文本片段/模板扩展器。设定简短缩写 → 在任何 App 中输入缩写后自动替换为完整文本（类似 TextExpander 但更轻量、买断制）。

- **定价**：$4.99 买断（TextExpander 年付 $40 的 1/10）
- **目标用户**：需要频繁输入重复文本的工作者（客服、医生、法律、开发者）
- **SF Symbol**：`"textformat.abc.dottedunderline"`

## 原生 API 强制实现

| 功能 | 强制使用的原生 API |
|------|------------------|
| 键盘输入事件 | `CGEvent` + `CGEventTap`（`kCGEventKeyDown` + postEvent） |
| 文本替换 | `CGEvent.post` 模拟退格 + 输入 |
| 片段存储 | `JSONEncoder` + `FileManager` 磁盘 |
| 分组管理 | `Codable` 树形结构 |
| 搜索 | `String.localizedStandardContains` |
| 同步 | `NSUbiquitousKeyValueStore`（轻量）/ `CloudKit`（重量） |
| 快捷键 | `CGEvent` + `addGlobalMonitorForEvents` |

### 工作方式

```
在任意 App 中：
1. 输入 ";thank"（缩写前缀 + 缩写）
2. TextPilot 检测到匹配 → 自动删除 ";thank"
3. 替换为完整内容
```

### 性能要求

- **键盘监听**：使用 `CGEventTap` 仅监听 keyDown 事件，仅当输入触发前缀后才开始匹配
- **匹配算法**：输入前缀后实时匹配缩写，使用 Trie 树加速匹配（内存 < 1MB）
- **CGEventTap 优化**：匹配失败后立即返回，不阻塞事件流
- **排除密码输入**：检测 `NSApp.isActive` + SecureInput 状态自动暂停
- **存储**：片段以 JSON 文件存储，变更时增量写入
- **启动速度**：< 200ms，所有片段在启动时预加载到内存 Trie 树
- **监听开销**：空闲时 CPU < 0.01%，仅在有键盘事件时消耗资源

### 关键实现

```swift
// 使用 Trie 树加速缩写匹配
actor SnippetTrie {
    private var root = TrieNode()

    func insert(keyword: String, snippet: Snippet) {
        var node = root
        for char in keyword {
            node = node.children[char, default: TrieNode()]
        }
        node.snippet = snippet
    }

    func search(keyword: String) -> Snippet? {
        var node = root
        for char in keyword {
            guard let next = node.children[char] else { return nil }
            node = next
        }
        return node.snippet
    }
}
```

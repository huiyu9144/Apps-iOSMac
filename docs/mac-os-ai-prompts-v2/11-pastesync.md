## 项目概述

macOS 菜单栏剪贴板历史管理器，支持 iCloud 跨设备同步。比 ClipFlow 更强大——不仅记录剪贴板历史，还能通过 iCloud 在 Mac 间同步，支持图片预览、片段收藏、富文本。

- **定价**：免费（50 条历史）→ $3.99 买断（无限历史 + iCloud 同步）
- **目标用户**：多台 Mac 设备用户、频繁复制粘贴的效率型用户
- **SF Symbol**：`"arrow.left.arrow.right.circle"`

## 原生 API 强制实现

| 功能 | 强制使用的原生 API |
|------|------------------|
| 剪贴板监听 | `NSPasteboard` + `NSPasteboard.ChangeCount` 轮询（0.5s） |
| iCloud 同步 | `NSUbiquitousKeyValueStore`（配置/收藏） + 本地文件 + `CloudKit`（大数据） |
| 富文本渲染 | `NSAttributedString` + `NSTextView` |
| 图片缩略图 | `NSImage` + `CGImageSourceCreateThumbnailAtIndex` |
| 搜索 | `String.localizedStandardContains` + `NSPredicate` |
| 快捷键 | `CGEvent` + `addGlobalMonitorForEvents` |

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 🔍 搜索框 | 面板顶部 | 实时搜索历史内容（逐字过滤） |
| 历史条目 | 中部列表 | 点击该条目 → 自动复制到剪贴板 + 短暂 toast 提示「已复制」 |
| ★ 收藏按钮 | 条目右侧 | 切换收藏状态，收藏的条目出现在上方「收藏片段」区域 |
| 📌 收藏片段 | 底部区域 | 快速点击复制，右键可编辑/删除 |
| iCloud 图标 | 右上角 | 灰色=未同步，蓝色=已同步，点击可打开设置 |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 快捷键

- `⌘ + ⇧ + V`：呼出历史面板（全局快捷键）
- 在面板中 `↑↓` 选择，`Enter` 复制选中项
- 在面板中 `⌘+Delete` 删除选中项

### 性能要求

- **剪贴板监听**：使用 `NSPasteboard.ChangeCount` 轮询（0.5s 间隔），而非 NSTimer 高频检测
- **历史存储**：使用 `JSONEncoder` + 磁盘文件，路径 `~/Library/Application Support/PasteSync/`
- **iCloud 同步**：使用 `NSUbiquitousKeyValueStore` 同步配置和收藏，`CloudKit` 同步完整历史
- **缩略图生成**：使用 `CGImageSourceCreateThumbnailAtIndex` 生成 120x90 缩略图缓存
- **搜索**：纯内存搜索，使用 `String.localizedStandardContains`，300ms 防抖
- **回收机制**：历史条目达到上限时，自动删除最旧的未收藏条目
- **不活跃时暂停**：面板关闭后暂停剪贴板监听（0.5s → 2s 间隔降频）

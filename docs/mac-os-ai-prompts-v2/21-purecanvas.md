## 项目概述

macOS 菜单栏纯色背景板工具。一键将整个屏幕或指定区域变为纯色背景，用于截图背景、绿幕抠图、屏幕检测、色彩比对等场景。比打开 Photoshop 画个色块快 100 倍。

- **定价**：$1.99 买断（极低价走量工具）
- **目标用户**：需要纯色背景的任何人——截图用户、视频创作者、设计师、摄影师、远程演示者
- **SF Symbol**：`"rectangle.on.rectangle"`

## 原生 API 强制实现

| 功能 | 强制使用的原生 API |
|------|------------------|
| 全屏覆盖 | `NSScreen` + 无边框 `NSWindow`（`.fullScreen` / `.borderless`） |
| 区域浮窗 | `NSPanel`（`.nonactivatingPanel`）+ 拖拽缩放 `NSTrackingArea` |
| 颜色设置 | `NSColorPanel` / `NSColorWell` 系统取色器 |
| 快捷键 | `CGEvent` + `addGlobalMonitorForEvents` |
| 多显示器 | `NSScreen.screens` 遍历 |
| 窗口层级 | `NSWindow.level`（`.floating` / `.normal` + 自定义） |
| 颜色格式 | `NSColor` → Hex/RGB 格式转换 |

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 当前颜色预览 | 面板顶部 | 显示当前颜色名称 + Hex 值 |
| 模式切换 | 面板中部 | Radio 切换全屏/区域模式 |
| 🎨 最近颜色网格 | 面板中部 | 点击立即切换为该颜色（共 10 个槽位，自动记录历史） |
| ⬤ 打开取色器 | 面板中部 | 弹出 `NSColorPanel` 系统原生取色器 |
| 色值输入框 | 取色器旁 | 直接输入 Hex（#RRGGBB），实时更新 |
| 不透明度滑块 | 色值下方 | 0-100%，支持半透明背景 |
| 宽/高输入框 | 区域大小区 | 区域模式下设置面板尺寸 |
| 固定比例/自由缩放 | 尺寸输入旁 | 固定比例时锁定宽高比 |
| 普通层/置顶层 | 显示层级区 | 普通层=背景、置顶层=浮在所有窗口之上 |
| 🖥 启用背景 | 面板底部 | 创建/显示纯色背景窗口 |
| ⏹ 关闭背景 | 面板底部 | 关闭/隐藏纯色背景窗口 |
| ⌘⇧B 快捷键 | 面板底部 | 全局切换背景显示/隐藏 |
| ⚙️ 齿轮 | 右上 | 设置窗口 |
| 退出应用 | 底部 | 关闭背景 + `NSApplication.shared.terminate(nil)` |

### 性能要求

- **全屏窗口**：使用 `NSWindow` + `.fullScreen` 或自定义全屏尺寸，无渲染开销（纯色不需要任何绘图）
- **区域窗口**：使用 `NSPanel` + `NSVisualEffectView`（仅背景色），拖拽使用 `windowFrame` API
- **颜色切换**：通过 `NSWindow.backgroundColor` 直接设置，毫秒级切换
- **取色器**：使用系统 `NSColorPanel`，不自定义取色 UI
- **窗口层级**：`.normal` 普通层置于桌面之上/其他窗口之下；`.floating` 浮动层始终可见
- **最近颜色**：存储在 `UserDefaults`，最多 10 条
- **内存占用**：< 5MB（没有图片、没有复杂视图层级）
- **多显示器**：全屏模式下每个 `NSScreen` 创建一个 `NSWindow`，同步设置颜色

### 使用场景示例

| 场景 | 操作 |
|------|------|
| **App 截图干净背景** | 打开 PureCanvas 选白色 → 全屏 → 截图 |
| **绿幕抠图** | 选绿色 (#00FF00) → 全屏 → 录制/截图 |
| **屏幕坏点检测** | 选红色 → 全屏 → 观察屏幕是否有异常像素 |
| **色彩比对** | 选特定颜色 → 全屏 → 将实物放在屏幕旁比对 |
| **视频会议背景** | 选白色/浅灰 → 全屏 → 摄像头对着屏幕（纯色 = 虚拟背景的廉价替代） |
| **设计稿衬底** | 选灰色 → 区域模式 → 将设计稿截图放在旁边对比 |

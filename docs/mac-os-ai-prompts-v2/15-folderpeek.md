## 项目概述

macOS 菜单栏文件夹快速访问工具。将常用文件夹固定到菜单栏 → 点击图标即可浏览文件夹内容、快速打开文件。比在 Finder 里层层点击快 10 倍。

- **定价**：$2.99 买断
- **目标用户**：需要频繁访问特定文件夹的 Mac 用户（开发者、设计师、内容创作者）
- **SF Symbol**：`"folder"`

## 原生 API 强制实现

| 功能 | 强制使用的原生 API |
|------|------------------|
| 文件浏览 | `FileManager` + `NSFileWrapper` |
| 文件图标 | `NSWorkspace.shared.icon(forFile:)` |
| 文件预览 | `QLPreviewPanel`（Quick Look） |
| 拖拽支持 | `NSDragOperation` + `NSPasteboard` |
| 文件夹监听 | `DispatchSourceFileSystemObject`（监听文件变更） |
| 打开文件 | `NSWorkspace.shared.open(_:)` |
| 最近文件 | `NSMetadataQuery`（Spotlight 查询） |
| 文件夹图标 | `NSImage` 系统图标 + `NSWorkspace.shared.icon(forFile:)` |

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 固定文件夹列表 | 顶部 | 显示已固定的文件夹，点击切换当前浏览的文件夹 |
| 📁 文件夹 | 列表 | 点击展开浏览该文件夹内容 |
| × 删除 | 文件夹右侧 | 从固定列表中移除 |
| + 添加文件夹 | 列表底部 | 弹出 `NSOpenPanel` 选择文件夹 |
| ▶ 子文件夹 | 文件列表 | 点击展开浏览子文件夹内容 |
| 📄 文件 | 文件列表 | 点击调用 `NSWorkspace.shared.open(_:)` 打开 |
| 👁 预览 | 文件行 | 鼠标 hover 时出现，点击使用 `QLPreviewPanel` Quick Look 预览 |
| 📋 拖拽 | 文件行 | 支持从面板拖拽文件到任何 App |
| 最近文件 | 底部 | 显示最近从 FolderPeek 打开的文件 |
| ⚙️ 齿轮 | 右上 | 设置 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- **文件列表加载**：使用 `FileManager.contentsOfDirectory(at:)` 后台线程异步加载
- **文件夹监听**：使用 `DispatchSourceFileSystemObject` 监听文件变更（新建/删除/修改）
- **图标缓存**：`NSCache` 缓存文件图标，最大 100 项，内存压力时自动释放
- **缩略图**：使用 `NSWorkspace.shared.icon(forFile:)` 系统图标，不生成自定义缩略图
- **排序/过滤**：纯内存操作，不涉及磁盘 I/O
- **文件夹切换**：使用 `async/await` 异步加载，切换时显示 loading 动画
- **Quick Look**：使用系统 `QLPreviewPanel`，不集成自定义预览
- **拖拽**：使用 `NSDraggingSession` 原生拖拽

## 项目概述

macOS 菜单栏浮动速记板。从菜单栏点击即可打开一个极简记事窗口，支持 Markdown、标签分类、快速搜索。比系统 Stickies 更轻量、比 Bear/Notion 更快。

- **定价**：$2.99 买断
- **目标用户**：需要快速记事的 Mac 用户、临时笔记需要者
- **SF Symbol**：`"note.text"`

## 原生 API 强制实现

| 功能 | 强制使用的原生 API |
|------|------------------|
| 文本编辑 | `NSTextView` + `NSAttributedString` |
| Markdown 渲染 | 系统 `NSAttributedString` Markdown 初始化（macOS 14+ 原生） |
| 文件存储 | `JSONEncoder` + `FileManager` 磁盘文件 |
| 自动保存 | `Timer.publish(every:tolerance:)` 防抖 + `NSNotification` 保存 |
| 全局快捷键 | `CGEvent` + `addGlobalMonitorForEvents` |
| 搜索 | `String.localizedStandardContains` |

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 🔍 搜索 | 面板顶部 | 搜索笔记标题和内容 |
| 笔记列表 | 中部 | 点击展开笔记编辑 |
| 📝 标题 | 笔记项 | 编辑标题（自动保存） |
| 📌 标记 | 笔记项右侧 | 标记为重要/置顶 |
| + 新建笔记 | 列表底部 | 打开空白笔记 |
| 标签下拉 | 编辑弹窗顶部 | 选择/输入标签（自动补全） |
| 编辑区 | 编辑弹窗 | 富文本编辑，支持 Markdown 快捷键 |
| 📋 复制 | 编辑弹窗底部 | 复制笔记全部内容 |
| 🗑 删除 | 编辑弹窗底部 | 删除确认后删除 |
| ★ 收藏 | 编辑弹窗底部 | 切换收藏状态 |
| ⚙️ 齿轮 | 主面板右上 | 设置 |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 快捷键

- `⌘ + ⇧ + N`：快速新建笔记（全局快捷键）
- `⌘ + ⇧ + F`：快速搜索笔记
- `⌘ + S`：手动保存（实际上是防抖自动保存，但手动更保险）

### 性能要求

- **自动保存**：编辑停止后 2 秒自动保存，使用 `Timer.publish` 防抖
- **存储格式**：每个笔记一个 JSON 文件，`~/Library/Application Support/ScratchPad/Notes/`
- **搜索**：纯内存过滤，300ms 防抖
- **列表懒加载**：笔记超过 50 条时分页加载
- **编辑区**：使用 `NSTextView` 而非 SwiftUI `TextEditor`（性能更好，原生富文本支持）
- **启动速度**：列表预加载最后 20 条，其余异步加载
- **自动清理**：未收藏且超过 6 个月未编辑的笔记，提示清理

> 本提示词需要配合 `_shared-requirements.md` 一起使用。所有通用的架构、多语言、性能、关闭/退出机制、设计规范、原生 API 强制要求等均已在该文件中定义，此处不再赘述。

## 项目概述

macOS 菜单栏快捷词典/翻译工具。选中任何文字 → 快捷键弹出翻译/释义浮窗。使用系统原生词典 + URLSession 翻译 API（免费）。比系统三指查词更快、更灵活。

- **定价**：$3.99 买断
- **目标用户**：需要频繁查词/翻译的多语言工作者、外语学习者
- **SF Symbol**：`"book.closed"`

## 原生 API 强制实现

| 功能 | 强制使用的原生 API |
|------|------------------|
| 本地词典 | `NSSpellChecker` + 系统词典服务（`DCSCopyTextDefinition`） |
| 在线翻译 | `URLSession` + 免费翻译 API（DeepL Free / LibreTranslate） |
| 文字选中检测 | `AXUIElement`（选中文本）或 `NSPasteboard`（检测复制） |
| 语音朗读 | `NSSpeechSynthesizer` |
| 快捷键 | `CGEvent` + `addGlobalMonitorForEvents` |
| 取词 | `NSAccessibility` |

### 快捷键

- `⌘ + ⇧ + D`：查词/翻译当前选中文字（全局快捷键）
- 选中文字 + 快捷键 → 弹出浮动小窗显示结果
- `⌘ + ⇧ + T`：快速翻译模式（直接替换选中文字为翻译结果）

### 所有按钮与交互路径

| 元素 | 位置 | 点击行为 |
|------|------|---------|
| 🖹 输入框 | 顶部 | 手动输入要查的单词 |
| 🔍 查按钮 | 输入框旁 | 手动查词 |
| 查词结果 | 主区域 | 显示音标、词性、释义、例句 |
| 🔗 近义词 | 释义下方 | 展开显示更多近义词和反义词 |
| 🔊 发音 | 结果区域 | 使用 `NSSpeechSynthesizer` 朗读单词 |
| 📋 复制 | 结果区域 | 复制释义到剪贴板 |
| ⭐ 收藏 | 结果区域 | 收藏该单词到生词本 |
| 翻译模式 | 翻译区 | 切换源语言/目标语言 |
| 收藏列表 | 底部 | 点击查看收藏的单词 |
| ★ 收藏单词 | 收藏列表 | 点击重新查词 |
| ⚙️ 齿轮 | 右上 | 设置（语言对、词典源、快捷键） |
| 退出应用 | 底部 | `NSApplication.shared.terminate(nil)` |

### 性能要求

- **本地查词**：使用 `DCSCopyTextDefinition` 系统原生查词接口，零网络延迟
- **翻译 API**：使用 `URLSession` + 免费翻译 API，结果缓存 1 小时
- **选中文本检测**：使用 `AXUIElementCopyAttributeValue` 读取当前选中，不用模拟 Cmd+C
- **浮动小窗**：使用 `NSPanel`（non-activating panel），轻量无焦点
- **收藏存储**：`UserDefaults` + `NSUbiquitousKeyValueStore` iCloud 同步
- **发音**：使用 `NSSpeechSynthesizer` 系统合成语音
- **缓存策略**：最近 100 条查词结果缓存内存，App 退出时清空

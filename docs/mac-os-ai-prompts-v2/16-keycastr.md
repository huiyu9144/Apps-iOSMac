## 参考通用要求

> 本提示词需要配合 `_shared-requirements.md` 一起使用。所有通用的架构、多语言、性能、关闭/退出机制、设计规范、原生 API 强制要求等均已在该文件中定义，此处不再赘述。

> ⚠️ 与开源项目 KeyCastr 同名但功能不同：本工具专为录屏/演示场景设计，内置样式选择、快捷键屏蔽过滤、隐私模式。

## 项目概述

macOS 菜单栏按键可视化工具。录屏/演示时在屏幕上显示按键操作（⌘C、⌘V、键入的文字等）。帮助观众看清你的操作步骤。

- **定价**：$3.99 买断
- **目标用户**：录屏创作者、开发者、讲师、演示者
- **SF Symbol**：`"keyboard"`

## 原生 API 强制实现

| 功能 | 强制使用的原生 API |
|------|------------------|
| 键盘事件捕获 | `CGEvent` + `CGEventTap`（`kCGEventKeyDown`） |
| 屏幕叠加层 | `NSScreen` + 无边框 `NSWindow`（`NSPanel` + `.floating` 级别） |
| 文本渲染 | `NSAttributedString` + `CATextLayer` |
| 动画 | `CABasicAnimation` / `CAKeyframeAnimation`（CoreAnimation） |
| 快捷键过滤 | `CGEvent` 检查 modifiers + keycode |
| 截图 | `CGWindowListCreateImage` |

### 性能要求

- **按键捕获**：使用 `CGEventTap`（`.tapDefaultPerSession`），回调极低延迟
- **屏幕渲染**：使用 `NSPanel` + `CATextLayer`（CoreAnimation），不使用 SwiftUI 实时渲染（减少 GPU 开销）
- **显示样式**：每个样式预渲染为 `CALayer` 模板，切换时仅替换图层内容
- **隐私模式**：密码输入时自动暂停（通过检测 `NSApp.isActive` 变化 + secure text input 状态）
- **CPU 占用**：空闲时不执行任何代码，CGEventTap 仅在按键时触发
- **内存占用**：< 5MB（仅保留最后 5 个按键的显示图层）
- **辅助功能权限**：首次启动引导用户开启

### 关键实现

```swift
// CGEventTap 按键捕获（使用 CoreGraphics 原生 API）
let eventMask = (1 << CGEventType.keyDown.rawValue)
guard let eventTap = CGEvent.tapCreate(
    tap: .cgSessionEventTap,
    place: .headInsertEventTap,
    options: .defaultTap,
    eventsOfInterest: CGEventMask(eventMask),
    callback: { (proxy, type, event, refcon) -> Unmanaged<CGEvent>? in
        let manager = Unmanaged<KeyCastManager>.fromOpaque(refcon!).takeUnretainedValue()
        manager.handleKeyEvent(event)
        return Unmanaged.passUnretained(event)
    },
    userInfo: Unmanaged.passUnretained(keyCastManager).toOpaque()
) else {
    // 处理权限未授权情况
    return
}
```

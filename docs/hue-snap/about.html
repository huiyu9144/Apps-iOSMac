HueSnap - About

HueSnap is a smart color picker for macOS that helps you capture, manage, and convert colors from anywhere on your screen.

Key Features

Screen Pick

Pick any color from the screen

Multi-Format

HEX, RGB, HSL, SwiftUI Color and more

Tailwind Support

Match colors to Tailwind CSS palette

Color History

Save and organize picked colors

System Requirements

  • macOS 12.0 or later
  • At least 2GB RAM
  • At least 50MB free storage

Usage Guide

Basic Operations

  1. Click the menu bar icon
  2. Pick a color from the screen
  3. Copy the color code in your preferred format

About This App

NetMeter is a real-time network monitoring tool for macOS that displays upload and download speeds directly in your menu bar. Keep track of your network activity at a glance.

  • Real-Time Speed Monitor - View live upload and download speeds in the menu bar with customizable units (Kbps, Mbps, KB/s, MB/s).
  • Per-Process Traffic - See which applications are consuming the most bandwidth with detailed per-process breakdowns.
  • Data Usage Reports - Track daily, weekly, and monthly data usage with automatic reports and history logs.
  • Connection Alerts - Get notified when network connections drop or when specific data thresholds are reached.

Permissions & Privacy

Required Permissions:

  • Network Access - Required to monitor network interfaces and traffic data. Some advanced features may require a helper tool with elevated privileges.

Privacy Commitment: All network monitoring data is processed locally. No network usage data is ever transmitted to any server. We do not collect or log your browsing activity.

Frequently Asked Questions

  • What does NetMeter monitor? - Real-time upload and download speeds, per-process traffic, and weekly reports.
  • Does it require admin privileges? - Some advanced features may require a helper tool with elevated privileges.
  • Can I set data usage limits? - Yes, you can set monthly data caps and receive alerts when approaching the limit.
  • Does it work with VPN connections? - Yes, NetMeter monitors all active network interfaces including VPN tunnels.
  • How do I uninstall NetMeter? - Quit the app and delete it from your Applications folder. If you installed a helper tool, it will be removed automatically.
  • The app won't launch? - Ensure your Mac meets the minimum requirements: macOS 14.0 or later.

Troubleshooting

  • Speed readings show 0 - Check that your network interface is active. Try switching between Wi-Fi and Ethernet in settings.
  • Helper tool installation fails - Go to System Preferences > Privacy & Security to approve the helper tool installation, then retry.
  • Per-process data not showing - This feature requires the helper tool. Ensure it is properly installed and approved.
  • Data usage resets unexpectedly - Check that the data logging database is not corrupted. Reset usage stats in settings if needed.

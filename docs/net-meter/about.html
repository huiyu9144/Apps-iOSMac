NetMeter - About

NetMeter is a network traffic monitor for macOS that tracks real-time upload and download speeds and provides detailed traffic reports.

Key Features

Real-Time Monitor

Live upload/download speed display

Traffic Charts

Visual traffic history charts

Weekly Report

Detailed weekly traffic summary

Process Tracking

Monitor traffic by application

System Requirements

  • macOS 12.0 or later
  • At least 2GB RAM
  • At least 50MB free storage

Usage Guide

Basic Operations

  1. Launch the app to see real-time speeds in the menu bar
  2. Click for detailed charts
  3. View weekly traffic reports

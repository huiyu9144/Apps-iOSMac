## 项目概述

PrivacyGen 是一个隐私政策和用户条款自动生成器。独立开发者、App 开发者和网站站长通过回答一系列简单问题（收集哪些数据？用什么分析工具？面向哪个地区的用户？），即可自动生成合规的隐私政策和用户条款文档。支持 GDPR/CCPA/COPPA 多法规、多语言生成，并提供免费托管页面。免费版可生成基础文档，$4.99 买断无限生成 + 托管。

## 目标用户

- 独立开发者 —— 开发了 App 或网站，需要快速生成隐私政策
- App 开发者 —— iOS/Android 应用上架需要隐私政策
- 网站站长 —— 个人博客/商业网站需要合规文档
- SaaS 创始人 —— 产品上线前需要用户条款和隐私政策
- 自由职业者 —— 为客户建站时批量生成法律文档

## 定价

| 版本 | 价格 | 功能 |
|------|------|------|
| Free | $0 | 生成基础隐私政策（英文）、托管 1 个页面、有限法规选项 |
| Pro | $4.99 买断 | 无限生成、支持 GDPR/CCPA/COPPA、多语言（中/英/日/德/法）、导出 HTML/PDF/Markdown、无限托管页面 |

买断制适用（一次性使用工具，用户生成一次后不需要持续付费）。

### 工具界面

**问答生成器 `/generate`**（核心流程）：
```
/generate → 问答流程（多步骤，每步一题）
├── Step 1: 文档类型
│   └── 隐私政策 / 用户条款 / 两者都生成
├── Step 2: 应用信息
│   ├── 应用/网站名称
│   ├── 公司名称（可选）
│   ├── 联系邮箱
│   └── 网站/App 下载链接
├── Step 3: 数据收集
│   ├── 是否收集用户邮箱/姓名？（是/否）
│   ├── 是否使用 Cookies？（是/否）
│   ├── 使用哪些第三方服务？
│   │   └── Google Analytics / Stripe / Firebase / Sentry / 其他（多选）
│   └── 是否收集位置信息？（是/否）
├── Step 4: 法规选择
│   ├── GDPR（欧洲用户）
│   ├── CCPA（加州用户）
│   ├── COPPA（13 岁以下儿童保护）
│   └── 通用（其他地区）
├── Step 5: 语言选择
│   └── 中文 / 英文 / 日语 / 德语 / 法语
└── Step 6: 生成 & 预览
    ├── 实时预览生成的文档
    ├── 编辑模式（可手动微调文本）
    └── 确认生成
```

**托管页面 `/p/:id`**：
```
/p/xxxx → 托管展示页
├── 文档标题（应用/网站名称）
├── 更新日期
├── 文档正文（结构清晰，带锚点目录）
├── 分享按钮
└── "由 PrivacyGen 生成" 脚注
```

**管理后台 `/app`**（Pro 功能）：
```
/app → 用户管理
├── 已生成的文档列表
├── 编辑 / 重新生成
├── 下载按钮（PDF/HTML/Markdown）
└── 删除
```

## 所有按钮与交互路径

| 按钮/交互 | 位置 | 触发动作 |
|-----------|------|---------|
| 「开始生成」 | 首页 Hero | 跳转 `/generate` Step 1 |

| 「托管此页面」 | 预览页 | 生成永久链接 `/p/:id` |
| 「分享」 | 托管页 | 复制分享链接 |
| 「管理我的文档」 | 预览页 | 跳转 `/app` |

## 性能要求

- 问答流程 `/generate` 每步切换 < 300ms（纯前端切换，无等待）
- 文档生成 API 响应 < 3s（后端组装模板）
- 托管页 `/p/:id` 纯静态渲染，首屏 < 1s
- PDF 生成在客户端完成（使用浏览器打印或 jsPDF），不占用服务器资源
- 文档模板用 JSON 存储，按法规/语言分片，生成时拼接，避免重复查库
- 托管页支持 CDN 缓存，Cache-Control 设置为 1 天

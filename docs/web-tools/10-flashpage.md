## 项目概述

FlashPage 是一个产品上线倒计时 / Coming Soon 页面生成器。SaaS 创始人和营销人员在产品正式上线前，通过选择模板、填写产品名/上线日期/邮箱收集配置，一键生成倒计时落地页，用于提前收集潜在用户邮箱、预热市场。免费版 1 个页面（子域名），$5/月解锁自定义域名 + 分析功能。

## 目标用户

- SaaS 创始人 —— 产品上线前搞预热活动，收集种子用户
- 营销人员 —— 新品发布前的预告页面
- 独立开发者 —— 新产品上线前建立期待
- 创业团队 —— 快速搭建 MVP 预热落地页

## 定价

| 版本 | 价格 | 功能 |
|------|------|------|
| Free | $0 | 1 个页面（子域名 `your-page.flashpage.app`）、5 个模板、邮箱收集（上限 100 条） |
| Pro | $5/月 | 自定义域名、全部模板（15 个）、无限邮箱收集、CSV 导出、Google Analytics 集成、社交媒体链接 |

买断制不适用（持续使用工具，页面需要持续托管，采用订阅模式）。

## 核心功能与 UI 流程

### 首页 Landing

```
/ → Landing Page
├── Hero: "产品还没上线？先让世界知道" + CTA "创建你的 Coming Soon 页面"
├── 痛点场景:
│   ├── "自己写页面太麻烦" → "选择模板，3 分钟搞定"
│   ├── "用 Carrd 要 $19/月" → "FlashPage 免费起步，Pro 只要 $5"
│   └── "没人知道你的产品" → "提前收集邮箱，上线即通知"
├── 模板展示: 3-4 个精选模板预览图（可点击放大）
├── 定价卡片: Free vs Pro 对比
├── FAQ: 6-8 个常见问题
└── Footer
```

### 工具界面

**构建器 `/create`**（核心流程）：
```
/create → 构建流程（分步向导）
├── Step 1: 选择模板
│   ├── 模板网格展示（缩略图 + 名称）
│   ├── 每个模板标注 "Free" 或 "Pro"
│   └── 点击选中后进入下一步
├── Step 2: 填写信息
│   ├── 产品名称
│   ├── 一句话描述（副标题）
│   ├── 上线日期（日期选择器，自动计算倒计时）
│   ├── 产品 Logo 上传（可选）
│   ├── 背景颜色/图片（可选）
│   └── 社交媒体链接（Twitter / GitHub / Product Hunt 等，可选）
├── Step 3: 邮箱收集配置
│   ├── 启用/禁用邮箱收集
│   ├── 自定义收集提示语（如 "抢先体验"）
│   ├── 自定义提交按钮文字
│   └── 设置收集后的跳转链接或感谢语
├── Step 4: 高级设置
│   ├── Google Analytics 测量 ID（Pro 功能）
│   ├── 自定义域名（Pro 功能）
│   └── 自定义 meta 标签标题/描述
└── Step 5: 生成 & 发布
    ├── 实时预览（右侧/弹窗预览最终效果）
    ├── 倒计时动画演示
    └── 点击 "发布" 生成页面
```

**展示页 `/p/:id`**：
```
/p/xxxx → 公开 Coming Soon 页面
├── 全屏倒计时（天/时/分/秒，动态更新）
├── 产品名称 + 描述
├── Logo（如有）
├── 邮箱输入框 + 订阅按钮
├── 社交媒体图标链接
├── 页面底部 "Powered by FlashPage"（小字）
└── 背景（纯色/渐变/图片，取决于模板）
```

**管理后台 `/app`**：
```
/app → 用户管理
├── 已发布页面列表
├── 每个页面的状态（在线/暂停）
├── 订阅邮箱列表 + 导出 CSV
├── 页面编辑（重新进入构建流程）
├── 页面设置（域名、GA、meta 标签）
└── 删除页面
```

## 所有按钮与交互路径

| 按钮/交互 | 位置 | 触发动作 |
|-----------|------|---------|
| 「创建 Coming Soon 页面」 | 首页 Hero | 跳转 `/create` Step 1 |
| 「预览模板」 | 首页模板展示 | 弹窗放大预览模板效果 |
| 「免费创建」 | 首页定价卡片 Free | 跳转 `/create` |
| 「升级到 Pro」 | 首页定价卡片 Pro | 跳转 Stripe 结账 |
| 「选择此模板」 | `/create` Step 1 | 选中模板，进入 Step 2 |
| 「下一步」 | 构建器每步底部 | 校验后进入下一步 |
| 「上一步」 | 构建器每步底部 | 返回上一步 |
| 「预览」 | 构建器 Step 5 | 弹窗/新窗口预览页面 |
| 「发布」 | 构建器 Step 5 | 生成页面，跳转管理后台 |
| 「复制页面链接」 | `/app` 后台 | 复制 `/p/:id` 或自定义域名 |
| 「导出 CSV」 | `/app` 后台 | 下载收集的邮箱列表 |
| 「编辑」 | `/app` 后台 | 重新进入构建器，预填已有数据 |
| 「暂停」 | `/app` 后台 | 暂停页面展示（返回 404） |
| 「删除」 | `/app` 后台 | 确认后删除页面 |
| 「域名设置」 | `/app` 后台 | 打开自定义域名配置弹窗（Pro） |
| 「GA 设置」 | `/app` 后台 | 输入 GA 测量 ID（Pro） |
| 「订阅邮箱」 | `/p/:id` 展示页 | 提交邮箱，显示感谢信息 |

## 性能要求

- 展示页 `/p/:id` 必须是纯静态页面，首屏 < 1s
- 倒计时使用客户端 JavaScript 计算，不依赖服务器时间同步（允许小幅偏差）
- 模板使用预编译 HTML，运行时仅替换变量（产品名、日期等），不执行模板引擎
- 展示页无任何外部请求（除 Google Analytics 外），确保快速加载
- 邮箱提交 API < 500ms，提交后立即显示感谢信息
- 展示页支持 Cache-Control `public, max-age=3600`，缓存 1 小时
- 倒计时动画使用 `requestAnimationFrame`，不消耗额外 CPU

About This App

FindDup helps you reclaim disk space by quickly identifying and removing duplicate files on your Mac. Using content-based hashing, it finds exact duplicates regardless of file names.

  • Content-Based Detection - Uses SHA-256 file hashing to identify exact duplicates, even if file names differ.
  • Smart Scan Modes - Choose between quick scan (same name + size) or deep scan (full content hash) for thorough detection.
  • Safe Deletion - Preview duplicates before deleting. Removed files are sent to Trash for easy recovery.
  • Visual Comparison - Side-by-side preview for images and documents to confirm before deletion.

Permissions & Privacy

Required Permissions:

  • File Access - Required to read and scan files for duplicate detection. You grant access to specific folders via the standard macOS file picker.

Privacy Commitment: All file scanning and hashing is performed entirely on your device. No file content or metadata is ever uploaded to any server.

Frequently Asked Questions

  • How does FindDup detect duplicates? - It uses file content hashing (SHA-256) to identify exact duplicates regardless of file name.
  • Is it safe to delete files? - You can preview files before deletion. Deleted files go to Trash for recovery.
  • Can I scan external drives? - Yes, you can select any mounted volume including external drives and network shares.
  • Does it find similar photos? - FindDup finds exact duplicates only. For visually similar images, use a dedicated photo comparison tool.
  • How do I uninstall FindDup? - Quit the app and delete it from your Applications folder. No additional cleanup needed.
  • The app won't launch? - Ensure your Mac meets the minimum requirements: macOS 12.0 or later.

Troubleshooting

  • Scan taking too long - Large folders with many files take longer. Try narrowing your scan to specific folders instead of the entire disk.
  • Permission denied for some folders - macOS may restrict access to system folders. Grant folder access via the file picker when prompted.
  • False positives in results - Ensure you are using deep scan mode. Quick scan matches by name and size only.
  • App crashes during scan - This may happen with very large file sets. Try scanning smaller batches of folders separately.

FindDup - About

FindDup is an efficient duplicate file finder that helps you quickly locate and clean up duplicate files on your disk.

Key Features

Smart Scanning

Scan custom paths to quickly identify duplicates

Hash Matching

Precise content-based matching algorithm

Batch Delete

One-click deletion of duplicate files

Safe Preview

Preview file content before deletion

System Requirements

  • macOS 12.0 or later
  • At least 4GB RAM
  • At least 100MB free storage

Usage Guide

Basic Operations

  1. Select a folder to scan
  2. Click the scan button to start searching
  3. View the scan results
  4. Select duplicate files to delete

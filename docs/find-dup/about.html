🔍 FindDup - 产品说明

FindDup 是一款高效的重复文件查找工具，帮助您快速定位和清理磁盘上的重复文件。

主要功能

智能扫描

支持自定义扫描路径，快速识别重复文件

哈希匹配

基于文件内容的精确匹配算法

批量删除

支持一键删除重复文件

安全预览

删除前可预览文件内容

系统要求

  • macOS 12.0 或更高版本
  • 至少 4GB RAM
  • 至少 100MB 可用存储空间

使用说明

基本操作

  1. 选择要扫描的文件夹
  2. 点击扫描按钮开始查找
  3. 查看扫描结果
  4. 选择要删除的重复文件

关于 FormatQuick

FormatQuick 是一款 macOS 菜单栏工具，帮助您快速批量转换图片格式。支持 JPG、HEIC、GIF 格式互转，可调整图片质量和尺寸，保留照片信息。

常见问题

支持哪些图片格式？

目前支持 JPG、HEIC、GIF 三种输出格式。输入支持常见的图片格式（PNG、JPG、HEIC、WebP、GIF、TIFF、BMP 等）。

转换后的文件保存在哪里？

转换后的文件保存在临时文件夹中，转换完成后会自动打开文件夹供您查看。您可以将文件移动到任意位置。

如何调整图片质量？

在选项区域可以通过滑块调整输出质量，百分比越高画质越好，文件也越大。建议 JPG 设为 30%-70% 以获得较好的平衡。

调整尺寸有什么作用？

开启后可以设定图片的最大宽度和高度，程序会自动缩放图片。支持适应（保持比例）、填充（裁剪适应）、拉伸三种模式。

保留照片信息是什么？

开启后会保留图片的 EXIF 信息（如拍摄日期、相机型号、GPS 位置等）。

About FormatQuick

FormatQuick is a macOS menu bar tool for batch image format conversion. It supports JPG, HEIC, and GIF output formats, with adjustable quality and resize options, while preserving photo metadata.

FAQ

What formats are supported?

Output: JPG, HEIC, GIF. Input: common image formats including PNG, JPG, HEIC, WebP, GIF, TIFF, BMP, etc.

Where are converted files saved?

Converted files are saved to a temporary folder, which opens automatically after conversion. You can move them to any location.

How to adjust image quality?

Use the slider in the options area. Higher percentage means better quality but larger file size. For JPG, 30%-70% is recommended for a good balance.

What does resize do?

When enabled, you can set max width and height. Three modes: Fit (maintains aspect ratio), Fill (crops to fit), Stretch (distorts to fit).

What is "Keep Photo Info"?

When enabled, EXIF metadata (date taken, camera model, GPS location, etc.) is preserved in the output.

# Skill Creator

## 功能说明

本技能用于帮助用户创建新的自定义 Skill，自动生成技能结构和模板。

## 使用场景

当用户需要：
- 创建新的自定义技能
- 为特定开发工作流
- 封装重复性任务
- 标准化特定领域专业知识

## 创建 Skill 的步骤

1. 与用户对话，了解他们想要的技能功能
2. 收集以下信息：
   - 技能名称 (name)：使用小写字母和连字符
   - 技能描述 (description)：清晰描述技能的用途和使用场景
   - 技能的主要功能和指令
   - 示例用法
   - 指南和最佳实践

3. 创建技能结构：
   ```
   .trae/skills/[skill-name/
   └── SKILL.md
   ```

4. 生成 SKILL.md 内容格式：
   ```markdown
   ---
   name: skill-name
   description: 技能描述
   ---
   
   # 技能名称
   
   ## 功能说明
   [详细描述技能功能]
   
   ## 使用场景
   [说明何时使用该技能]
   
   ## 示例
   - 示例 1
   - 示例 2
   
   ## 指南
   - 指南 1
   - 指南 2
   ```

5. 验证技能是否符合用户需求，进行必要的调整

## 示例

> "帮我创建一个 iOS 开发相关的 skill"

## 指南

- 技能名称应该简洁明了
- 描述要详细说明技能的用途
- 提供清晰的使用示例帮助用户理解何时使用该技能

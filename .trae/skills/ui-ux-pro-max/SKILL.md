# UI UX Pro Max

## 功能说明

UI UX Pro Max 是一个专注于设计智能（Design Intelligence）的 AI 技能库。它将专业 UI/UX 知识库直接注入 AI 编程助手，让 AI 生成的设计告别"AI 味"，达到专业设计师水准。

**Star**: 25k+
**官网**: [uupm.cc](https://uupm.cc/)

## 功能特点

### 智能设计系统生成器（v2.0 核心功能）

自动分析项目需求并生成完整的设计系统，包括：
- 设计风格推荐
- 配色方案
- 字体搭配
- 效果和动画
- 反模式警告

### 工作流程

```
用户请求 → 多领域搜索（5个并行搜索） → 推理引擎 → 完整设计系统输出
```

## 交付前检查清单

- 不要用 emoji 作为图标（使用 SVG: Heroicons/Lucide）
- 所有可点击元素添加 cursor:pointer
- 悬停状态有平滑过渡（150-300ms）
- 浅色模式文本对比度不低于 4.5:1
- 键盘导航可见焦点状态
- 尊重 prefers-reduced-motion
- 响应式支持 375px, 768px, 1024px, 1440px
